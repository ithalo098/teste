# Manual do Usuário - Minhas Tarefas Desktop

## 1. Primeiros Passos
O **Minhas Tarefas Desktop** é uma aplicação simples e prática para organizar tarefas do dia a dia no Grau Técnico.

## 2. Adicionando uma Tarefa
1. No painel à esquerda, digite o título da tarefa (ex: "Entregar trabalho de Redes").
2. Se quiser, adicione detalhes no campo de descrição.
3. Escolha a categoria (Hardware, Redes, Programação, Banco de Dados, etc.).
4. Defina o nível de prioridade (Baixa, Média, Alta).
5. Escolha a data de entrega e clique no botão **Adicionar Tarefa**.

## 3. Concluindo uma Tarefa
- Para marcar uma tarefa como feita, basta clicar na caixinha de seleção (checkbox) ao lado do título. O texto ficará riscado e o contador de concluídas será atualizado na hora.
