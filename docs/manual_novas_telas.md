# Manual das Novas Funcionalidades - Henrique

## 1. Temporizador Pomodoro
- Para iniciar a técnica de Pomodoro (25 minutos de estudo focado seguidos de 5 minutos de pausa), acesse a tela `views/pomodoro.html` e clique em **Iniciar Foco**.

## 2. Quadro Kanban
- Permite visualizar suas tarefas distribuídas horizontalmente nas colunas **A Fazer**, **Em Andamento** e **Concluído**.
