# Registro de Contribuições - Henrique Matos (HenriqueMatosof)

## Resumo das Entregas
Neste projeto em trio, o integrante Henrique ficou responsável por:
1. Criação do sistema de Tags e Etiquetas customizáveis.
2. Implementação do temporizador Pomodoro para auxílio nos estudos.
3. Criação da visão de Quadro Kanban com colunas de status.
4. Módulo de Bloco de Anotações rápidas para as aulas de laboratório.
5. Sistema de backup e exportação JSON.
6. Suporte completo a impressão com folha de estilo @media print.
7. Testes unitários para validar as novas regras de negócio.
