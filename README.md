## 💻 Sobre a Aplicação
O projeto é um gerenciador de tarefas intuitivo para estudantes e técnicos, permitindo cadastrar, acompanhar e filtrar tarefas acadêmicas e de laboratório.

### Recursos:
- Cadastro de tarefas com título, descrição, categoria, prioridade e prazo
- Contadores automáticos no topo (Total, Pendentes e Concluídas)
- Filtragem rápida por status e prioridade
- Pesquisa instantânea por texto
- Modais para edição e confirmação de exclusão
- Notificações visuais (Toasts) a cada ação
- Suporte a Modo Escuro
- Persistência contínua com LocalStorage

## 🚀 Como Executar o Projeto

1. Ter o Node.js instalado na máquina.
2. Clonar o repositório:
   ```bash
   git clone https://github.com/ithalo098/teste.git
   ```
3. Entrar na pasta:
   ```bash
   cd teste
   ```
4. Instalar as dependências:
   ```bash
   npm install
   ```
5. Iniciar o app:
   ```bash
   npm start
   ```
